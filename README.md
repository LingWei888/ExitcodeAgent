# ExitcodeAgent

一个纯前端、单机使用的智能体工作台：项目、会话、模型接入和账号数据都只存在当前浏览器里，聊天时直接请求你自己配置的模型服务，不依赖任何后端接口。

## 当前实现（纯前端本地业务版）

- **唯一本地账号**：第一次打开时创建本机账号并设置口令；之后每次打开只需口令解锁。没有注册入口，一台浏览器只保留一个账号。
- **加密本地存储**：账号、项目、会话、消息、模型密钥和当前选择统一存入 localStorage 的单条加密 Vault（PBKDF2 派生密钥 + AES-GCM 加密），刷新不丢失，锁定后内存中的密钥与数据即时清除。
- **真实项目与真实会话**：项目、会话、消息历史全部是真实数据，没有示例会话或假模型。新建项目、新建会话、切换模型、发送消息都会持久化。
- **项目可关联服务器目录**：在“项目目录”里可以为当前项目选择一个本地目录，读取目录内容并授权后，右侧状态面板会显示真实的文件列表。目录句柄单独保存在 IndexedDB，刷新后仍可恢复，也会重新请求读取权限。
- **真实模型直连**：支持的接入类型为 Claude（Anthropic）、OpenAI 兼容接口（DeepSeek、通义千问、GLM 等）和 Ollama。支持流式输出、停止生成、连接测试、Token 用量统计和会话内切换模型。

## 启动

前置：Node.js 20+ 和 pnpm。

```bash
pnpm install
pnpm dev:web
```

浏览器打开 `http://localhost:5173`。首次打开创建本机账号；之后输入口令解锁。

生产预览：

```bash
pnpm build:web
pnpm preview:web
```

## 使用流程

1. 首次创建本机账号并设置至少 8 位的口令。
2. 在“模型与密钥”里添加至少一个模型接入，填好接口地址、API Key 和模型名，建议先测试连接。
3. 新建项目；项目创建后可随时在右侧“工作区状态”选择服务器目录。
4. 在项目下新建会话，发送消息后会直接流式调用所选模型。
5. 顶栏可锁定账号，锁定后所有本地数据回到加密态。

## 目录结构

```
apps/
├── api/                  # 预留目录，当前版本不使用后端
└── web/                  # Vue 3 + Vite 前端
    └── src/
        ├── components/   # 侧栏、对话面板、状态抽屉、模型设置等
        ├── services/     # 加密存储、目录读取、模型流式直连
        ├── store.ts      # 全局状态与持久化调度
        └── views/        # 登录视图与工作区视图
```

## 数据与安全边界

- 数据只在本机浏览器内流转，不上传任何平台服务。
- 口令不落明文；完整本地数据整体加密保存，解密只在解锁期间发生在浏览器内存里。
- API Key 随 Vault 加密保存，列表中只显示掩码。
- 浏览器无法直接写文件或执行命令，因此当前版本提供真实的目录读取与模型对话；文件写入、命令执行等能力留给后续接入本地运行时或可选的后端沙箱。

## 跨域说明

Claude 官方接口支持浏览器直连。OpenAI 兼容端点与 Ollama 是否允许跨域取决于服务端配置，例如 Ollama 可以设置 `OLLAMA_ORIGINS`。密钥保存在本机，请勿在公用电脑上使用。
